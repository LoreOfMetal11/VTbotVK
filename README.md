# VTbotVK

Информационный бот ВКонтакте для абитуриентов и студентов факультета вычислительной техники Пензенского государственного университета (ФВТ ПГУ).

Бот работает от имени сообщества VK: принимает личные сообщения, распознаёт текстовые команды и показывает кнопочное меню. Проект написан на Python; основная реализация находится в `vkbot.py`.

## Возможности

- Главное меню и отдельные разделы для поступления, частых вопросов и деканата.
- Справочная информация о факультете, его расположении, деканате и получении справок.
- Темы о направлениях подготовки, экзаменах, документах, стоимости обучения, общежитии и стипендиях.
- FAQ из 13 вопросов: можно выбрать тему текстом или отправить `вопрос 12` / `faq 12`.
- Получение до трёх первых публикаций из ленты новостей ПГУ с заголовками и ссылками.
- Кэширование новостей на 5 минут; при ошибке загрузки — ответ со ссылкой на ленту и кэширование на 1 минуту.
- Повторное подключение после сетевых ошибок и отправка ответа без клавиатуры при ошибке VK 912.

## Состояние ветки firstver

Это начальная версия проекта. Навигация и обработка команд реализованы, но значительная часть справочной информации пока содержит `[пусто]`. Перед использованием бота как полноценного справочника эти поля нужно заполнить и проверить актуальность уже внесённых сведений.

Бот не использует нейросеть: ответы выбираются по заранее заданным командам и их вариантам. Неизвестные сообщения сейчас получают ответ `[пусто]`. Сообщения из бесед игнорируются — обрабатываются только личные сообщения пользователей сообществу.

## Технологии

- Python 3.
- `vk_api` — работа с VK API, Bot Long Poll и клавиатурами.
- `requests` — HTTP-запросы к сайту ПГУ.
- `beautifulsoup4` — разбор HTML страницы новостей.
- Стандартная библиотека Python: `logging`, `re`, `time`, `getpass`, `urllib.parse`.

## Установка

Клонируйте нужную ветку и перейдите в каталог проекта:

```bash
git clone --branch firstver https://github.com/LoreOfMetal11/VTbotVK.git
cd VTbotVK
```

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его:

```bash
# Linux / macOS
source .venv/bin/activate

# Windows PowerShell
.venv\Scripts\Activate.ps1

# Windows cmd
.venv\Scripts\activate.bat
```

Установите зависимости:

```bash
python -m pip install vk_api requests beautifulsoup4
```

Файла `requirements.txt` в этой ветке пока нет; версии зависимостей не зафиксированы.

## Настройка сообщества VK

Для запуска нужны ключ доступа сообщества и его числовой ID.

1. Включите сообщения сообщества.
2. Создайте ключ доступа сообщества с разрешением на работу с сообщениями.
3. Включите Bot Long Poll API и событие входящего сообщения (`message_new`).
4. Для кнопочного меню разрешите использование возможностей ботов и клавиатуры в настройках сообщества.

Не публикуйте ключ доступа в репозитории и не отправляйте его другим пользователям. Скрипт запрашивает ключ через `getpass`, поэтому ввод не отображается в терминале. Настройки из `.env` в текущей реализации не загружаются.

## Запуск

```bash
python vkbot.py
```

Введите запрошенные значения:

```text
Ключ сообщества: <ключ доступа>
ID сообщества: <положительный числовой ID>
```

После запуска напишите сообществу `начать`, `привет` или `/start`. Для остановки процесса нажмите `Ctrl+C`.

## Примеры команд

| Команда | Действие |
| --- | --- |
| `начать`, `/start`, `меню` | Открыть главное меню |
| `о факультете` | Показать описание ФВТ и ссылку на сайт |
| `хочу поступить` | Открыть раздел поступления |
| `направления`, `егэ`, `документы` | Показать соответствующую справочную тему |
| `частые вопросы` | Показать список FAQ |
| `вопрос 12` | Показать информацию о деканате |
| `справка` | Показать информацию о получении справки |
| `новости пгу` | Загрузить публикации из ленты ПГУ |

Команды приводятся к нижнему регистру; `ё` заменяется на `е`, лишние пробелы убираются. Распознавание выполняется по точному совпадению нормализованного текста с известной командой.

## Структура и логика

```text
VTbotVK/
├── README.md   # Описание проекта и инструкция запуска
└── vkbot.py    # Данные, меню, команды, новости и основной цикл бота
```

Основные части `vkbot.py`:

- `TOPICS` — тексты справочных ответов.
- `FAQ` — список вопросов и связанных тем.
- `ALIASES` и `COMMANDS` — варианты команд и их соответствие темам.
- `make_keyboard()` — создание клавиатур разделов.
- `make_answer()` — выбор ответа и меню по тексту сообщения.
- `get_news()` — загрузка, разбор и кэширование новостей.
- `send_answer()` — отправка сообщения через VK API.
- `main()` — ввод настроек и обработка событий Bot Long Poll.

Чтобы дополнить справочник, заполните `TOPICS`. Для новых вариантов команд измените `ALIASES`; для новых пунктов FAQ — `FAQ`; для кнопок — раскладки в `make_keyboard()`.

## Ограничения

- Справочник содержит незаполненные поля и требует проверки актуальности данных.
- Парсер новостей зависит от структуры HTML и формата ссылок на сайте ПГУ.
- Кэш новостей хранится только в памяти процесса и сбрасывается при перезапуске.
- База данных, сохранение диалогов и передача вопросов оператору не реализованы.
- Автоматические тесты и файл с зафиксированными зависимостями в этой ветке отсутствуют.
