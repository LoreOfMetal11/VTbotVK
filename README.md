# VTbotVK

Информационный бот ВКонтакте для знакомства с кафедрой «Вычислительная техника» Пензенского государственного университета.

Бот работает от имени сообщества: принимает личные сообщения, распознаёт текстовые команды и показывает кнопочное меню. Основная реализация находится в `vkbot.py`.

## Состояние ветки secondver

В этой версии бот переориентирован с факультета на кафедру ВТ. Обновлены приветствие, меню, справочные ответы и источник новостей. Заведующей кафедрой в текстах указана Карамышева Надежда Сергеевна.

Сведения о направлениях обучения, технологиях и профессиях подготовлены по буклету кафедры 2025 года; сведения о заведующей уточнены отдельно. Перед публикацией и использованием необходимо проверять актуальность данных о текущем наборе и контактах.

Админ-панель с SQLite подготовлена отдельным черновиком, но в эту ветку пока не добавлена. Текущий `vkbot.py` не создаёт `bot.db`, не запрашивает ID администраторов и не поддерживает `/админ`.

## Возможности

- Информация о кафедре и ссылка на её сайт.
- Выбор уровня обучения: бакалавриат, специалитет, магистратура и аспирантура.
- Описание направлений, профилей и сроков обучения.
- Ответы о навыках, технологиях и вариантах работы после выпуска.
- Контакты приёмной комиссии и полезные ссылки.
- Расписание, военный учебный центр и баллы прошлых лет отправляются только ссылками. Числовых проходных баллов и отдельного раздела экзаменов в ответах нет.
- FAQ из 11 вопросов с выбором по тексту или номеру: `вопрос 1`, `faq 1`.
- Получение до трёх первых найденных публикаций из ленты кафедры: https://vt.pnzgu.ru/news.
- Кэш новостей на 5 минут; при ошибке или отсутствии найденных публикаций — `[пусто]`, ссылка на ленту и кэш на 1 минуту.
- Повторное подключение после сетевых ошибок и повторная отправка без клавиатуры при ошибке VK 912.

Кнопка «Буклет кафедры» сохранена для дальнейшей доработки. Сейчас она возвращает `[пусто]`: отправка PDF и фотографий страниц не подключена. Раздела сотрудничества и списка компаний нет.

## Главное меню

```text
[ О кафедре          ] [ Направления обучения ]
[ Чему научат        ] [ Работа после выпуска ]
[ Буклет кафедры     ] [ Новости ВТ           ]
[ Поступление        ] [ Полезные ссылки     ]
```

Дополнительные клавиатуры предусмотрены для информации о кафедре, уровней обучения, навыков, поступления и полезных ссылок.

## Технологии

- Python 3.
- `vk_api` — VK API, Bot Long Poll и клавиатуры.
- `requests` — загрузка страницы новостей.
- `beautifulsoup4` — разбор HTML.
- Стандартная библиотека: `logging`, `re`, `time`, `getpass`, `urllib.parse`.

База данных для текущей версии не нужна. Ответы и раскладки меню хранятся непосредственно в Python-коде.

## Установка

```bash
git clone --branch secondver --single-branch https://github.com/LoreOfMetal11/VTbotVK.git
cd VTbotVK
python -m venv .venv
```

Активируйте окружение командой для своей системы:

```bash
# Linux / macOS
source .venv/bin/activate

# Windows PowerShell
.venv\Scripts\Activate.ps1

# Windows cmd
.venv\Scripts\activate.bat
```

Установите зависимости:

```bash
python -m pip install vk_api requests beautifulsoup4
```

В ветке пока нет `requirements.txt`, версии зависимостей не зафиксированы. При использовании Anaconda или Spyder установите библиотеки в то окружение, в котором запускается скрипт.

## Настройка сообщества VK

Нужны ключ доступа сообщества и положительный числовой ID этого же сообщества.

1. Включите сообщения сообщества.
2. Создайте ключ сообщества с разрешениями на сообщения и управление сообществом (`messages`, `manage`).
3. Включите Bots Long Poll API и событие входящего сообщения (`message_new`).
4. Включите возможности ботов для работы клавиатуры.

Не публикуйте ключ в репозитории, переписке и снимках экрана. Скрипт запрашивает его при запуске через `getpass`. Загрузка настроек из `.env` и переменных окружения в текущем `vkbot.py` не реализована.

## Запуск

```bash
python vkbot.py
```

Введите:

```text
Ключ сообщества: <ключ доступа>
ID сообщества: <положительный числовой ID>
```

Напишите сообществу `привет`, `начать`, `/start` или `меню`. Остановка — `Ctrl+C`. Для получения новых сообщений процесс бота должен оставаться запущенным.

Бот обрабатывает только личные сообщения пользователей сообществу; сообщения из бесед игнорируются.

## Примеры команд

| Команда | Действие |
| --- | --- |
| `привет`, `/start`, `главное меню` | Главное меню |
| `о кафедре`, `кафедра вт` | Информация о кафедре |
| `контакты кафедры`, `заведующая` | Имя заведующей и ссылка на сайт |
| `направления обучения` | Выбор уровня обучения |
| `бакалавриат`, `специалитет`, `магистратура`, `аспирантура` | Соответствующая программа |
| `чему научат`, `технологии` | Навыки и технологии |
| `работа после выпуска`, `кем работать` | Варианты профессий |
| `поступление`, `хочу поступить` | Меню для поступающих |
| `приёмная комиссия` | Контакты и ссылка |
| `полезные ссылки` | Меню ссылок |
| `расписание`, `вуц`, `баллы прошлых лет` | Соответствующая ссылка |
| `новости`, `новости вт` | Публикации из ленты кафедры |
| `частые вопросы`, `faq`, `задать вопрос` | Список FAQ |
| `вопрос 6` | Информация о заведующей и ссылка на сайт кафедры |
| `буклет кафедры` | Заготовка раздела: `[пусто]` |

Старая команда `новости пгу` сохранена как дополнительный вариант: она тоже загружает ленту кафедры ВТ.

Команды приводятся к нижнему регистру; `ё` заменяется на `е`, лишние пробелы и крайние знаки `!?.` убираются. Затем выполняется точное сопоставление с известными командами. Бот не использует нейросеть; неизвестное сообщение получает `[пусто]`. Команда «Задать вопрос» не пересылает сообщение оператору.

## Как устроены новости

`get_news()` загружает HTML страницы `https://vt.pnzgu.ru/news` и извлекает ссылки на публикации с этого же домена. Сейчас принимаются адреса с путём вида `/news/год/месяц/день/номер`.

Бот убирает повторяющиеся ссылки и берёт до трёх первых подходящих публикаций в порядке страницы. Он не сортирует их по дате и не проверяет, относятся ли они к сегодняшнему дню. Это HTML-парсер, а не отдельный новостной API.

Доступность сайта для `requests` и соответствие текущей разметки шаблону нужно проверять при запуске. Изменение структуры ссылок или отказ сайта в доступе могут потребовать доработки парсера. Технические ошибки выводятся в журнал процесса; пользователю отправляется резервный ответ со ссылкой.

## Структура и редактирование

```text
VTbotVK/
├── README.md
└── vkbot.py
```

Основные структуры и функции:

| Элемент | Назначение |
| --- | --- |
| `TOPICS` | Тексты ответов и ссылки |
| `PROGRAMS_NOTE` | Общая приписка к программам обучения |
| `LAYOUTS` | Кнопки и их расположение |
| `TOPIC_SECTIONS` | Клавиатура после ответа на тему |
| `ALIASES`, `COMMANDS` | Варианты текстовых команд |
| `FAQ` | Вопросы и связанные темы |
| `normalize()` | Нормализация текста |
| `make_keyboard()` | Создание клавиатуры |
| `make_answer()` | Выбор ответа и раздела |
| `get_news()` | Загрузка и кэширование новостей |
| `send_answer()` | Отправка ответа |
| `main()` | Настройка подключения и цикл Long Poll |

Чтобы добавить обычную тему вручную, добавьте ответ в `TOPICS`, команды в `ALIASES` и кнопку в `LAYOUTS`. При необходимости дополните `TOPIC_SECTIONS` и `FAQ`. После изменения кода перезапустите бота. Нумерация FAQ формируется автоматически из порядка списка.

## Черновик админ-панели

Подготовлен отдельный прототип редактора в сообщениях VK. Он пока не включён в файлы этой ветки.

В прототипе предусмотрены:

- доступ по списку личных числовых VK ID;
- команда `/админ`;
- добавление текстовых ответов, ссылок и подменю;
- изменение названия, ответа, раздела и порядка кнопок;
- скрытие и удаление с подтверждением;
- сохранение меню в SQLite (`bot.db`) и журнал изменений;
- разбиение длинных меню на страницы.

Эти возможности описаны как направление дальнейшего развития, а не как функции текущего `vkbot.py`. Черновик требует отдельной проверки с VK перед интеграцией. Не следует создавать `bot.db` или вводить ID администратора при запуске текущей версии из этой ветки.

## Ограничения

- Актуальность справочных данных необходимо проверять отдельно.
- Буклет пока не отправляется.
- Произвольные вопросы, опечатки и свободные формулировки не распознаются автоматически.
- Нет базы данных, постоянного хранения диалогов, панели администратора и передачи вопросов оператору в текущем файле.
- Кэш новостей хранится в памяти и сбрасывается при перезапуске.
- Парсер зависит от доступности сайта, HTML и формата ссылок.
- Файлы автоматических тестов и зафиксированных зависимостей в ветку не добавлены; наличие кода не означает прохождения полноценной проверки через VK API.
